DeepSeek豆包 · 火山引擎

platform.deepseek.com → 左侧 API keys → 创建，得到一串 sk- 开头的密钥。语音合成与对话共用同一个 Key。

只需要一个 Key，没有 AppID / Token / cluster 那一套。鉴权头是 Bearer <key>，空格分隔。

console.volcengine.com → 语音技术 → 语音合成，开通后在「服务接口认证信息」里拿 AppID / Access Token / Cluster。

鉴权头是 Bearer;<token>，分号分隔，不是空格 —— 这里最容易写错。
