Wi-Fi 连接

只支持 2.4GHz 网络，5GHz 连不上。保存后设备会自动重连，约 5～20 秒。

填你家路由器的名字：手机 Wi-Fi 列表里看到的那个，也可以进路由器背面标签上找。 注意区分大小写，别带前后空格；中文名一般能连，但个别路由器会乱码，建议改成英文。

填手机连这个 Wi-Fi 时输的那串密码，8 位以上，区分大小写。 只有开放网络（不用密码的）才留空。改完在「引擎」页填 Key，才算配好。

密码不会被回显，也不显示已保存的密码。

跨设备是怎么连上的

固件没有开放跨域头，所以跨设备不能直连。本页用两种通道：

同源与中继
同源：直接打开设备自己的页面（例如 http://192.168.4.1），页面与设备同源，直连读写。
中继：从别处打开时，页面在后台加载目标设备的首页（也就是本页），由它代发请求再回传。要求目标设备固件里跑的是本页版本；老固件里的旧页面不会回应，会提示「设备页面无响应」。
https 页面访问 http 设备会被浏览器拦（混合内容），这种情况请用本地文件或 http 部署打开。
能用几台
每台中继设备会占用一个后台 iframe 和一条常驻连接，建议不超过 6 台。设备与手机／电脑要在同一局域网，跨网段、跨 VLAN 一般不通。
为什么不用 https
https 页面会被浏览器禁止访问 http://192.168.x.x（混合内容），所以本页必须用 http 打开才能控制板子；板子固件本身也只提供 http，没有证书。
想让别的电脑用固定网址打开：在局域网内任意一台机器上进到本文件所在目录，执行 python -m http.server 8080，别人的浏览器打开 http://那台机器IP:8080/ 即可；不在同一网络则连不到板子。
